# Квест «Команда Безопасика»

Интерактивный веб-квест (эскейп-рум) на Streamlit для профилактики вовлечения детей и подростков в экстремистскую и деструктивную деятельность. Игрок переписывается с «незнакомцами» в формате мессенджера, принимает решения и узнаёт, к чему они приводят. Проводник по игре — робот-щенок **Безопасик**.

> Учебный тренажёр. Все персонажи и ситуации вымышлены.

## Возможности

Пролог с историей Безопасика и вопросом «Хочешь начать игру?», затем ввод имени игрока (оно подставляется в реплики персонажей).

Три уровня с ветвящимися диалогами в стиле мессенджера: игрок выбирает один из готовых вариантов ответа и приходит к одной из концовок.

- **Уровень 1 — «Ошибся номером»**: незнакомец пишет с неизвестного номера. Учит не вступать в диалог без необходимости, не врать и не выдавать лишнего о себе.
- **Уровень 2 — «Друг семьи»**: «друг папы» просит купить подарочную карту и прислать код или выдать пароль. Учит замечать лесть, секретность, срочность и запросы конфиденциальных данных.
- **Уровень 3 — «Доброе дело»**: «волонтёрка» шаг за шагом выстраивает доверие и просит сфотографировать здание полиции. Показывает этапы вербовки и три красных флага: секретность, срочность, награда.

Система концовок: 🥇 золотой, 🥈 серебряный, 🥉 бронзовый щит, нейтральная и провальная концовки. После каждой Безопасик объясняет, что было сделано верно или неверно, и разбирает приёмы манипулятора.

Любой диалог можно пройти заново, не сбрасывая остальной прогресс. Провальные концовки предлагают переиграть уровень.

Боковая панель: прогресс по уровням, счёт (⭐ из 3), количество ошибок и кнопка «Начать заново».

Финальный разбор ошибок и **Памятка цифрового защитника** с золотыми правилами безопасности в интернете (доступна для скачивания).

Сертификат о прохождении квеста (`certificate.png`).

## Установка и запуск (локально)

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

Или запуск одной командой, которая сама поднимет сервер и откроет браузер:

```bash
python main.py
```

Приложение будет доступно на `http://localhost:8501`. Внешние файлы и база данных не нужны: всё состояние игры хранится в `st.session_state`.

## Запуск в Docker

```bash
docker compose up --build
```

Контейнер называется `kvest-bezopasika`, порт `8501` проброшен наружу, перезапуск — `unless-stopped`.

## Структура проекта

```
app.py              — приложение: тексты, сценарии уровней, интерфейс
main.py             — точка входа: запускает Streamlit и открывает браузер
mascot.png          — портрет Безопасика
certificate.png     — сертификат о прохождении
requirements.txt    — зависимости
Dockerfile          — образ для запуска в контейнере
docker-compose.yml  — запуск через Docker Compose
.dockerignore       — исключения при сборке образа
```
