🐶 **Квест «Команда Безопасика»**
Интерактивный веб-квест (эскейп-рум) для детей и подростков по профилактике вовлечения в экстремистскую и деструктивную деятельность. Игрок переписывается с «незнакомцами» в формате мессенджера, принимает решения и узнаёт, к чему они приводят. Проводник по игре — робот-щенок Безопасик.
> Учебный тренажёр. Все персонажи и ситуации вымышлены.
**О чём игра**
Безопасик рассказывает, что в интернете встречаются люди, которые втираются в доверие, обещают подарки и «лёгкие деньги» или зовут в «секретную команду». Задача игрока — научиться замечать манипуляции, отличать правду от обмана и понимать, что делать в подозрительной ситуации. Главная мысль квеста: настоящая сила — остановиться, подумать и попросить помощи у взрослых.
Как проходит игра
**Пролог**. Три экрана с историей Безопасика и вопрос «Хочешь начать игру?». Ответы «Да» и «Нет» получают разные реплики, но ведут к одному и тому же старту.
**Знакомство**. Игрок вводит имя. Дальше оно подставляется в реплики персонажей, например, когда незнакомец спрашивает «Это `<имя>`?».
**Три уровня с ветвящимися диалогами**. Игрок выбирает один из готовых вариантов ответа, и сюжет идёт по соответствующей ветке к одной из концовок.
**Финал**. Разбор ошибок и памятка цифрового защитника.
**Уровень 1 — «Ошибся номером»**
Сообщение от незнакомого номера: человек якобы перепутал адресата. Учит не вступать в диалог без необходимости, не врать и не выдавать лишнего о себе.
Правила уровня: на незнакомый номер можно не отвечать; фраза «Извините, вы ошиблись» — безопасная и универсальная; не задавай незнакомцу лишних вопросов, чтобы не давать ему повод продолжить разговор.
**Уровень 2 — «Друг семьи»**
«Друг папы» пытается войти в доверие, ссылаясь на родителей, и просит купить подарочную карту и прислать код или выдать пароль от почты. Учит распознавать типичные приёмы мошенников: лесть, секретность, срочность, запрос конфиденциальных данных, нежелание подтвердить личность.
Правило: проверять информацию через сохранённые контакты и спрашивать родителей.
**Уровень 3 — «Доброе дело»**
Финальный «босс»: «волонтёрка» постепенно, в пять этапов, выстраивает доверие и в итоге просит сфотографировать здание полиции, требуя держать это в тайне, сделать «срочно» и пообещав награду. Уровень показывает, как выглядит вербовка: знакомство, поиск уязвимостей, ощущение значимости, конкретная просьба, три красных флага (секретность, срочность, награда). В качестве безопасных действий игрок может отказаться, привлечь родителей, потребовать подтверждение проекта или заблокировать контакт; при необходимости обратиться в полицию по номеру 102 или 112.
**Система концовок и оценки**
У каждого уровня несколько концовок: 🥇 золотой щит, 🥈 серебряный, 🥉 бронзовый, 🟡 нейтральная и ⚠️ провальная.
После каждой концовки Безопасик объясняет, что сделал игрок правильно или неправильно, и читает мини-лекцию с разбором приёмов манипулятора. После провальной концовки лекция пропускается, а игроку предлагается переиграть уровень.
Игроку засчитывается балл за безопасную концовку уровня (максимум 3).
Неудачные решения записываются в список ошибок для итогового разбора.
Любой диалог можно пройти заново, не сбрасывая остальной прогресс.
**Интерфейс**
Реплики оформлены как пузыри мессенджера: Безопасик с портретом, незнакомец, ответы игрока.
В боковой панели отображаются прогресс по уровням, счёт (⭐ из 3), число ошибок и кнопка «🔄 Начать заново».
Если рядом с `app.py` нет `mascot.png`, вместо портрета показывается эмодзи 🐶.
**Технологии**
Python
Streamlit — интерфейс и состояние игры (`st.session_state`)
Docker / Docker Compose — запуск в контейнере
Внешние базы данных и сервисы не нужны: всё состояние хранится в сессии.
**Структура проекта**
Файл	Назначение
`app.py`	Само приложение: тексты, сценарии уровней, интерфейс
`main.py`	Точка входа: запускает Streamlit и открывает браузер
`mascot.png`	Портрет Безопасика
`certificate.png`	Сертификат о прохождении
`requirements.txt`	Зависимости
`Dockerfile`, `docker-compose.yml`, `.dockerignore`	Запуск в Docker
**Запуск**
Локально
```bash
pip install -r requirements.txt

# вариант 1
streamlit run app.py

# вариант 2 — сам запустит сервер и откроет браузер
python main.py
```
Приложение откроется на `http://localhost:8501`.
В Docker
```bash
docker compose up --build
```
Контейнер называется `kvest-bezopasika`, порт `8501` проброшен наружу, перезапуск — `unless-stopped`.
